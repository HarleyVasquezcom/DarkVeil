real css filter · per-site whitelist · three dials

The veil you choose

DarkVeil darkens a page with a genuine CSS filter — invert, hue-rotated, sepia and brightness-tuned — and it only ever lands on the sites you put on your whitelist. Everywhere else stays exactly as it was.

REAL Genuine CSS filter

invert() + hue-rotate(180deg) + sepia() + brightness(), applied to the page root in real time.

WHITELIST Per-site, by choice

Veil only what you add. The probe verifies that non-whitelisted hosts stay pixel-identical to baseline.

DIALS Strength, sepia, brightness

Three sliders tune the veil; every change is persisted and re-applied instantly, including after reloads.

MINIMAL One permission

Just storage. No tabs, no webRequest, no remote code — the veil never leaves your machine.
